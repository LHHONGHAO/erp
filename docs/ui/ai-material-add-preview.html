说明：
1. 左页为独立路由页，顶栏标题固定「商品AI添加」，不随识别结果变化、不承载表单加载态。
2. 「选择图片」与「拍照」并列；选中后在同卡片内显示缩略图，可删除重选。
3. 属性框为类别选择按钮，未选类别或未选图片时底部「识别」禁用。
4. 点「识别」后仅弹出右侧标准弹层页（MobileModalPage 规范：蓝底 49px 顶栏 + 可滚动内容 + 白底底栏），左页状态保持不变。
5. 弹层内输入框继续走键盘输入弹层（.mm-ai-page 或 data-kb-overlay="on"）。
6. 弹层关闭后回到左页，图片与类别保留，可继续识别下一件。
