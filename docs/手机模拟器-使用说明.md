# 手机模拟器使用说明

本地开发手机版页面的两套工具，仅用于开发环境，不进入生产包。

## A. 内置模拟器页面

路由：`/mobile-preview`（仅非 production 环境注册，开发环境免登录白名单；iframe 内业务页仍需正常登录）。

启动方式：

```powershell
cd jshERP-web
npm run serve        # 端口 3000
```

浏览器打开 `http://localhost:3000/mobile-preview`。

功能：

- 机型库：iPhone SE 375×667 / iPhone 12 390×844 / iPhone 14 Pro Max 430×932 / Android 360×800 / iPad mini 768×1024
- 竖屏/横屏切换
- 缩放：自动（按窗口自适应）/ 100% / 75% / 50%
- 页面列表自动取自 `store.state.permission.routers`，支持下拉搜索；也可手动输入路径
- iframe 已声明 `allow="camera; microphone; clipboard-write; fullscreen"`，扫码页可在 localhost 下调起摄像头
- 记住上次预览路径（localStorage 键 `jsh_mobile_preview_path`）
- 刷新按钮通过变更 iframe `key` 强制重载；代码改动由 webpack HMR 自动热更新

原理：项目用手机端判定全部基于视口宽度（`window.innerWidth <= 768`、enquire.js `max-width: 767.99px`），iframe 内媒体查询按 iframe 自身视口计算，因此 390px 宽的 iframe 里页面自动进入手机端布局。

## B. 真机比例窗口（Chrome/Edge --app 模式）

脚本：`tools/open-mobile-preview.ps1`

```powershell
powershell -ExecutionPolicy Bypass -File tools\open-mobile-preview.ps1 `
    -Path /material/material_add -Device iPhone12 -Orientation portrait
```

参数：

| 参数 | 取值 | 默认 |
|---|---|---|
| `-Path` | 任意页面路径 | `/dashboard/analysis` |
| `-Device` | iPhoneSE / iPhone12 / iPhone14ProMax / Android360 / iPadMini | iPhone12 |
| `-Orientation` | portrait / landscape | portrait |
| `-BaseUrl` | 开发服务器地址 | `http://localhost:3000` |

说明：

- 以 `--app` 无地址栏模式打开，窗口尺寸即设备尺寸（高度 +32px 抵消系统标题栏）
- 使用独立浏览器配置目录 `.cache\mobile-preview-profile`（已加入 .gitignore），保证 `--window-size` 生效；首次使用需登录一次，登录态会保留
- 整页即移动布局，`vh/dvh`、滚动行为比 iframe 更接近真机，适合单机型日常调试

## 生产隔离机制

- `jshERP-web/src/config/router.config.js`：预览页与模版页路由仅在 `process.env.NODE_ENV !== 'production'` 时注册
- `jshERP-web/vue.config.js`：生产构建通过 `webpack.IgnorePlugin` 忽略 `MobilePreview|MobilePageDemo` 模块，产物中不残留相关 chunk
- `jshERP-web/src/permission.js`：免登录白名单仅在开发环境追加这两个路径

## 已知限制

- 扫码/摄像头依赖安全上下文：localhost 可用；局域网 IP 必须走 HTTPS
- 软键盘弹出、`dvh`、iOS Safari 底部工具栏、微信 WebView 缓存、真实触摸手势无法在桌面浏览器模拟，需局域网 HTTPS 真机验证（开发服务器已开 `host: 0.0.0.0`、`disableHostCheck`）
- 开发环境代理：`vue.config.js` 中 `devServer.proxy` 目标由 `VUE_APP_API_TARGET` 控制，本机后端为 HTTPS 自签名直连（`https://localhost:9999`），代理已配置 `secure: false`
