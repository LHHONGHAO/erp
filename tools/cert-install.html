JSH_ERP 手机扫码 · 证书安装说明

扫码需要调用摄像头，浏览器只在 HTTPS 安全连接下才允许获取摄像头权限。安装本系统的自签名证书后，即可正常扫码。

第一步：下载证书

下载证书（jsh-erp.cer） 下载 Windows 证书（jsh-erp.pfx）
下载后按下方对应系统的步骤安装。证书由本机自签名，仅供局域网内部使用。

第二步：安装并信任证书

  1. Android（Chrome / 系统浏览器）
    下载 jsh-erp.cer → 设置 → 安全 → 更多安全设置 → 加密与凭据 → 安装证书 → CA 证书 → 仍然安装 → 选择下载的 jsh-erp.cer → 安装完成。
  2. iPhone / iPad（Safari）
    用 Safari 下载 jsh-erp.cer → 允许下载描述文件 → 设置 → 已下载描述文件 → 安装 → 设置 → 通用 → 关于本机 → 证书信任设置 → 打开 “jsh-erp.local” 的完全信任 → 重新打开 Safari。
  3. Windows 电脑
    双击 jsh-erp.cer → 安装证书 → 本地计算机 → 将所有的证书都放入下列存储 → 受信任的根证书颁发机构 → 完成。
证书安装完成后，浏览器访问时不再提示“不安全”。如果安装前浏览器提示证书风险，请选择“高级 / 继续访问”进入本页。

第三步：返回扫码页面

确认使用下面的 HTTPS 地址访问系统，然后回到「零售销售开单」页面重新点击「扫码添加」并允许摄像头权限。

https://192.168.100.157:9999 进入系统
若仍然无法扫码：请检查浏览器的摄像头权限设置，确认未被系统或浏览器禁用；iPhone 需在“设置 → Safari → 相机”中选择“允许”。
